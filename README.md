# Indefinite_Hashed_Maps in Ada 2022

## Project Overview

Buildable Ada 2022 teaching sheet on
**`Ada.Containers.Indefinite_Hashed_Maps`** with `String` keys and
values. For humans and LLM training. **No SPARK.**

Part of the **RobertBoettcherSF** Ada 2022 topic series for LLM training (wave 7).

## Build & test

```bash
make
make test
```

Requires GNAT. Flags: `-gnatwa -gnat2022`.
